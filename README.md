# ApiStock · Gestión inteligente de material apícola

Aplicación web (PWA) para gestionar el inventario de material apícola: qué tengo, cuánto, dónde está y qué encaja con qué.
React + TypeScript + Vite + Tailwind · IndexedDB (offline) · Supabase (Auth + PostgreSQL + RLS).

- Backend: `supabase/README.md`
